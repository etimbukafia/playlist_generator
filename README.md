# playlist_generator
AI Playlist Generator is a Python-based application that interacts with the Spotify API to generate customized playlists based on user preferences. The application offers two modes: scheduling playlists at specific times or monitoring a file to create playlists in response to changes in a txt file, called 'bio.txt'. The content of this bio.txt serves as the prompt.

# Features
- Scheduler Mode: Automatically generates playlists at scheduled times (e.g., every morning at 10:00 AM).
To run this mode, start the application with """ python main.py --mode scheduler """
